## Version 2.0 — Custom Design Commerce & Design Persistence

**فاز دوم الگوریتم طراحی و سفارش لباس از این نقطه به‌عنوان مرجع معماری ثبت شده است.**

- هر طراحی یک **Design Code یکتا** دارد و در رابط طراحی از نام محصول به‌عنوان هویت طرح استفاده نمی‌شود.
- قیمت پایه طراحی فعلاً **۱,۰۰۰,۰۰۰ تومان** است و قیمت پیش‌فرض هر لیبل **۱۰۰,۰۰۰ تومان** است؛ این مقادیر برای انتقال بعدی به پنل مدیریت آماده‌اند.
- رنگ و سایز فقط برای انتخاب Variant و کنترل موجودی استفاده می‌شوند؛ قیمت Variant جایگزین قیمت پایه طراحی نمی‌شود.
- هر لایه دارای نوع، سمت لباس (**front/back**)، شناسه/کد/نام لیبل، مختصات نرمال‌شده، اندازه، زاویه، ترتیب لایه و در صورت متن، محتوای متن و استایل آن است.
- ناحیه چاپ به بدنه لباس محدود است و نواحی آستین، یقه و سطوح غیرقابل چاپ در الگوریتم رد می‌شوند.
- مشخصات هندسی مرجع لباس بر اساس الگوی فعلی ثبت شده‌اند: بدنه **47×68cm**، سرشانه **36cm**، یقه **14cm** و عمق یقه **9cm** و ابعاد آستین طبق الگوی مرجع؛ این داده‌ها در payload طراحی نیز نگهداری می‌شوند.
- برای طراحی، پیش‌نمایش دوبعدی **جلو و پشت** جداگانه تولید و ذخیره می‌شود؛ فایل‌ها خارج از دیتابیس نگهداری و فقط مسیر فایل در DB ثبت می‌شود.
- کلیک «افزودن به سبد خرید» طراحی را به‌صورت وضعیت **CART** ثبت می‌کند؛ «ذخیره طراحی» دیگر مسیر خرید مستقل نیست.
- هنگام ایجاد سفارش، Snapshot کامل طراحی داخل OrderItem ثبت می‌شود تا تغییرات بعدی لیبل، قیمت یا تنظیمات، سفارش قبلی را تغییر ندهد.
- فقط پس از پرداخت موفق، طراحی از وضعیت CART به **CONFIRMED** منتقل می‌شود و زمان نهایی شدن ثبت می‌گردد.
- طراحی‌های آپلودی کاربر به‌عنوان فایل Artwork مدیریت می‌شوند و محتوای باینری فایل داخل JSON/DB ذخیره نمی‌شود.
- معماری فعلی امکان توسعه پنل مدیریت برای قیمت پایه طراحی و قیمت هر لیبل را بدون تغییر الگوریتم اصلی فراهم می‌کند.
