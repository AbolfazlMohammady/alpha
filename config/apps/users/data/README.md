# Iranian province and city seed data

This snapshot is derived from [tafakoritech/Provinces-and-Cities-of-Iran-Dataset](https://github.com/tafakoritech/Provinces-and-Cities-of-Iran-Dataset), copyright (c) 2024 Mohammad Tafakori, under the MIT License; see `LICENSE`.

The snapshot contains 31 provinces and 1119 city records. The upstream dataset describes itself as incomplete for Fars province, so this is a useful baseline, not a guarantee that every administrative locality is covered. Update the snapshot from a reviewed source when a complete, validated official dataset is available.
