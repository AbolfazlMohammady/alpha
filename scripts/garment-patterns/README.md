# تولید الگوی دوبعدی لباس برای ALPHA

این ابزار با استفاده از پکیج‌های متن‌باز FreeSewing (مجوز MIT)، الگوهای واقعی و پارامتریک SVG تولید می‌کند؛ تصویر تزئینی یا ماکاپ ساده نیست. وابستگی `@freesewing/plugin-transform` نیز به‌صورت مستقیم نصب می‌شود تا واردات داخلی بسته `core-plugins` در همه محیط‌های npm درست resolve شود.

## روش پیشنهادی اجرا: Docker

نیازی به نصب Node.js یا npm روی ویندوز نیست. از ریشه پروژه ALPHA و در کنار فایل `docker-compose.yml` اجرا کن:

```powershell
docker-compose run --rm --no-deps garment-patterns
```

این دستور یک کانتینر موقت Node.js 22 اجرا می‌کند، وابستگی‌های npm را در volume مستقل Docker نصب می‌کند و اسکریپت تولید الگو را اجرا می‌کند. نیازی به ورود به کانتینر Django یا Restart کردن سرویس Django برای تولید فایل‌ها نیست.

در اولین اجرا، Docker ممکن است تصویر `node:22-bookworm-slim` را دریافت کند و npm نیز برای نصب پکیج‌ها به دسترسی شبکه نیاز دارد.

## خروجی

اسکریپت فایل‌های زیر را در `config/static/customizer/patterns/` می‌سازد:

- `tshirt.svg` — الگوی Teagan برای تیشرت آستین‌کوتاه
- `long_sleeve.svg` — الگوی Brian برای بالاتنه و آستین بلند
- `hoodie.svg` — الگوی Hugo شامل بدنه، آستین رگلان، کلاه و جیب
- `manifest.json` — اندازه صفحه، محدوده قطعات جلو/پشت و ناحیه پیشنهادی چاپ

فایل‌های تولیدشده در پوشه پروژه روی سیستم میزبان قرار می‌گیرند و به‌واسطه volume موجود، بلافاصله در کانتینر Django نیز قابل مشاهده هستند.

## اندازه‌گیری‌ها و محدودیت استفاده

مقادیر `measurements.json` فعلاً پروفایل نمونه سایز M بر حسب میلی‌متر هستند. پیش از استفاده برای محصول واقعی، باید با اندازه‌های واقعی لباس یا جدول سایزبندی موردنظر جایگزین شوند. خروجی نمونه بدون بررسی خیاط/الگوساز نباید مبنای برش یا تولید انبوه قرار گیرد.

## به‌روزرسانی یا اجرای مجدد

پس از تغییر `measurements.json` یا اسکریپت، همان دستور Docker را دوباره اجرا کن:

```powershell
docker-compose run --rm --no-deps garment-patterns
```

برای دیدن الگوها در استودیو، صفحه را با `Ctrl + F5` تازه‌سازی کن. در محیط Production پس از تولید فایل‌ها، باید `collectstatic` نیز اجرا شود.

## عیب‌یابی

وضعیت تصویر Node را بررسی کن:

```powershell
docker image ls node
```

برای دیدن لاگ‌های اجرای سرویس (در صورت حذف نکردن کانتینر موقت)، می‌توان اجرای معمول را بدون `--rm` انجام داد:

```powershell
docker-compose run --no-deps garment-patterns
```

اگر دانلود image یا نصب npm به خطای شبکه خورد، متن کامل خطا را بررسی کن؛ اجرای اسکریپت روی ویندوز یا داخل کانتینر Django جایگزین لازم نیست.
