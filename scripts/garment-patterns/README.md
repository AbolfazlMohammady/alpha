# تولید الگوی دوبعدی لباس برای ALPHA

این ابزار با استفاده از پکیج‌های متن‌باز FreeSewing (مجوز MIT)، الگوی SVG واقعی و پارامتریک تولید می‌کند؛ تصویر نمونه یا شکل تزئینی نیست.

## نیازمندی
- Node.js نسخه 20 یا جدیدتر
- npm و دسترسی به npm registry در زمان نصب پکیج‌ها

## اجرا در ویندوز

از ریشه پروژه ALPHA:

```powershell
cd scripts/garment-patterns
npm install
npm run generate
```

## خروجی
اسکریپت فایل‌های زیر را در `config/static/customizer/patterns/` می‌سازد:
- `tshirt.svg` — الگوی Teagan برای تیشرت آستین‌کوتاه
- `long_sleeve.svg` — الگوی Brian با آستین بلند
- `hoodie.svg` — الگوی Hugo شامل بدنه، آستین، کلاه و جیب
- `manifest.json` — اندازهٔ صفحه، محدودهٔ قطعات جلو/پشت و ناحیهٔ پیشنهادی چاپ

در `measurements.json` مقادیر نمونهٔ سایز M بر حسب میلی‌متر هستند. پیش از استفاده برای تولید واقعی، آن‌ها را با جدول سایزبندی و اندازهٔ محصول واقعی جایگزین کنید. خروجی این پروفایل، الگوی نمونه برای پیش‌نمایش است و بدون بررسی خیاط/الگوساز نباید مبنای برش یا تولید انبوه قرار گیرد.

پس از تولید، صفحهٔ طراحی را با `Ctrl + F5` تازه‌سازی کنید. تا قبل از اجرای موفق اسکریپت، نمای دوبعدی پیام «الگو تولید نشده» را نشان می‌دهد.
